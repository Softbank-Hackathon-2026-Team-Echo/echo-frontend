# 번역 용어표

화면 문구의 한국어·일본어 표기 기준이다. 코드 규칙은 [frontend-conventions](../.claude/rules/frontend-conventions.md) §13 를 따른다. 일본어는 AI 초안이고 사람 검수 전이다.

- **문체**: 한국어는 합니다체, 일본어는 です・ます체. 버튼·메뉴·표 머리는 명사나 짧은 동사로 끝낸다(`배포`, `デプロイ`).
- **그대로 쓰는 말**: EchoPort, GitHub, AWS, GCP, Azure, Kubernetes, K3s, IAM, API, URL, CPU, p95, SHA, Rego, SCC, Prowler, Kubescape, PASS·WARN·FAIL 같은 서버 값, `simulated` 배지.
- **숫자·단위**: 영어 그대로(`9 s`, `300 km`, `M7.2`).
