## 1. 목표

운영 API(`api.echoport.uk`)가 열렸으니 생성 타입 위에서 첫 실제 화면들을 만든다.

- 운영 OpenAPI 로 타입을 만들고 openapi-fetch 로 부른다.
- 대시보드에서 두 클라우드와 온프레의 상태를 환경 카드로 한 화면에 본다(#3).
- 서비스를 등록하고 버튼 한 번으로 배포해 공개 주소를 얻고, 이력에서 다시 배포한다(#4).
- 재난 버튼 한 번으로 재난이 생기고 경보 배너와 위험 거점이 뜬다(#13).

## 2. 범위

### 포함
- `pnpm gen:api` → `schema.d.ts`, `api`(openapi-fetch) + `unwrap`, `types.ts` 는 스키마 별칭
- SET 환경: 등록(종류별 configSchema 폼) · 수정 · 접속 다시 확인 · 삭제(이름 입력 확인)
- S01 대시보드(1차): 환경 카드 — 클라우드 · 위치 · 클러스터 버전·노드 · 트래픽 합 · 서비스별 역할·트래픽·버전·동기화 · 재난 위험
- SVC: 목록(어디서 서비스 중인지) · 등록(GitHub App 설치 안내) · 상세(환경별 연결 · 배포 이력 · 다시 배포 · 삭제) · 배포 다이얼로그(브랜치/커밋, 데모 실패 주입) · 배포 진행(단계 · 경과 · 결과 주소 · 실패 이유 · 되돌림 결과, 2초 폴링)
- S01-D 재난 시뮬레이션: 지진/태풍 · 진원지 · 규모 → 반경 · 위험/안전 미리보기 → 발생, 경보 배너(모든 화면) · 종료
- MSW: 환경 CRUD · 종류 · 접속 확인, 서비스 CRUD, 배포 요청(시간에 따라 단계 진행 · 실패 주입)

### 제외 (API 없음 → 다음 작업)
- 배포 로그(API 서버 4): 자리만 두고 "아직 없음" 안내
- 되돌리기 API(`rollback_of_id`, API 서버 4): 지금은 같은 커밋으로 새 배포
- 복제 지연 · Hot standby(인프라·API 서버 8): 카드에 `—`
- 토폴로지 캔버스(React Flow), 지도에서 진원지 찍기, 휴대폰 리모컨(S01-R)
- 대피 마법사(E01) — 배너의 "Plan evacuation" 은 빈 Evacuation 화면으로 간다
